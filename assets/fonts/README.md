# Atkinson Hyperlegible Next

The homepage, About page, GitHub index, and project index use the locally served Latin subset of Atkinson Hyperlegible Next (normal style, variable weights 200–800).

- Upstream: https://github.com/googlefonts/atkinson-hyperlegible-next
- Webfont source: https://fonts.googleapis.com/css2?family=Atkinson+Hyperlegible+Next:wght@200..800&display=swap
- License: SIL Open Font License 1.1; see `OFL.txt` in this directory.

Code and small technical labels use the visitor's installed monospace font.
