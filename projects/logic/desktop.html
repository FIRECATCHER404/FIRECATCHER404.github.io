Logic Studio for Windows

Build circuits on a minimal canvas with a compiled C++ engine and native Direct2D drawing. Includes reusable chips, named pins, 8/16-bit buses, RAM/ROM, program tools, and Command-controlled keyboard input. Press Tab to release keyboard capture. Free comments and directional, multi-channel send/receive tunnels are included in both editions. Version 2.7.4 adds distinct tunnel icons and one-bit send/receive pins. Older bus tunnels convert automatically when loaded.

The programmable RGB-16 computer has 128 KiB RAM, 128 KiB program ROM, and a screen made of 16,384 individual pixel nodes. The keyboard example runs a real ROM program that reads keys into RAM and controls the screen.
