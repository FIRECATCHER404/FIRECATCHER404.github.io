Logic Studio for Windows

Build circuits on a minimal canvas with a compiled C++ simulator and native Direct2D drawing. Includes logic gates, reusable chips, buses, RAM/ROM, keyboard input, program tools, comments, tunnels and debugging logs.

Version 2.9 includes Pixel-256: a programmable LS8 computer with 2 GiB of sparse RAM, editable ROM, 126 keyboard nodes, and 65,536 individual display pixels. Its default program lets you draw with A, erase with S, and move with the arrow keys. Tab releases keyboard capture. The example is also available in the browser edition.
