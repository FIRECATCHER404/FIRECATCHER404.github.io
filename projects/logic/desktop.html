Logic Studio for Windows

The desktop edition runs a compiled C++ circuit engine and draws through Direct2D. It is the main version for new features.

The RGB-8 v2 computer has 256 bytes of program ROM, 256 bytes of RAM, X/Y registers, assembly and hex program loading, and a memory viewer. Langton’s ant is included as a 106-byte program with a 4×4 byte matrix.
