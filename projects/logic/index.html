    Byte format & instruction guide
    Each instruction is four bytes: OP 00 LOW HIGH. For example, 10 00 2A 00 loads 002A (42) into A. B0 00 00 80 stores A at RAM word 8000. Branch operands are ROM word addresses; one instruction advances PC by two words / four bytes.
    01 halt ? 02 input → A ? 03 A → OUT ? 05 X ? A ? 08/09 X++/X-- ? 10 load immediate ? 20/30 add/subtract ? 70 jump ? 80/90 jump if zero/nonzero ? A0/B0 RAM load/store ? C0 load X ? E0 plot color at X ? E2 clear screen. Unused operands are 00 00.

      Signals, registers & 24-bit color
      SENDTUNNEL has inputs only. Placing it creates a linked RECEIVETUNNEL with outputs only on the chosen adjacent layer. Choose 1-16 inputs, with one bit per input. Moving either end preserves the link. COMMENT blocks move and resize freely; middle-click to edit their text. Legacy TUNNEL blocks still load.
      An RGBTUNNEL targets an RGB block at the same grid position on the selected adjacent layer. Its 24 inputs run clockwise: top left → right, right top → bottom, bottom right → left, left bottom → top. Bits are R7…R0, G7…G0, B7…B0 (most significant first). Hover a port to see its bit. RGB blocks display #RRGGBB and accept no ordinary wires. One RGB block receives one bus.
      PULSE has no inputs and flips once per simulation frame. Simulation speed sets the frame interval; 0 uses display frames at Turbo 1?. Raise the Turbo multiplier in Settings to run more simulation frames between screen updates. Pause freezes pulses and Step flips each one once. REGISTER stores one bit: top input D, bottom input CLK, output Q. It captures D only when CLK rises from 0 to 1, and holds its value between edges. Use eight registers in parallel to store a byte.
      Unconnected inputs are off. XOR is odd parity for any number of inputs. Feedback retains its last state; an oscillating circuit stops settling and shows a warning. Pause and Step advance one propagation stage. Save/export preserves signal states.
