Language reference

Start with a line. Each generation copies the previous drawing. By default, a copy joins at the previous curve’s endpoint.

clone
Make a new copy to transform.
turn right / turn left
Rotate the copy 90°. Add an angle for another turn: turn left 45.
scale 0.5
Resize the copy around its pivot.
move 1 0
Move the copy right by one seed unit. Positive Y moves up.
flip x / flip y
Mirror the copy horizontally or vertically.
pivot end
Choose start, end, center, or origin for the following copies.
clear
Replace the old drawing with the copies you make next.
seed triangle
Choose line, triangle, or square on the first line.

Transformations affect the latest copy. Each clone reads the previous generation. Use # for comments.
