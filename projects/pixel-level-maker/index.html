TRIGGER

What happens here?

The orange region blocks movement while closed. Opening it clears the matching artwork pixels; closing it restores them. No door graphic is added.

Draw the player's pixels in Artwork over this green physical region. Only those pixels move. Nothing is drawn for you.

Moving regions leave the cleared-area color behind. Other rooms use this region as an arrival point.

DO THESE IN ORDER

A trigger can enable another trigger, or fire it immediately. Disabled triggers must be enabled before they can fire.

Changes apply when you save.
A SMALL GUIDE

Paint it. Give it meaning. Play it.

1 · Paint the physics

Blue is floor. Pink is a wall. Dark pixels are outside the level. Water slows the player; hazards hurt and return them to a checkpoint. Draw a green player region too. The player moves top-down.

2 · Draw what it looks like

Switch to Artwork and use any color. One physical pixel can contain 1, 4, or 16 artwork pixels. Paint every visible thing yourself. Pixels over the green player region move with it. No graphics are supplied.

3 · Make things happen

Choose Trigger in Physics, drag its area, and configure its popup. Use entry or E interaction, add actions, link rooms, open painted door regions, show messages, and control other triggers.

4 · Take a walk

Play uses a fresh copy of your level. Move with WASD/arrows and interact with E. Escape returns to editing. Runtime door states and flags do not change your project.

Draw / B · Erase / E · Fill / F · Line / L · Box / R · Pick / I · Select / V · Space + drag pans · Ctrl Z undoes · Ctrl S saves. Use the room list to build more rooms. Export playable HTML makes a single offline file you can share.
