READY FOR MINECRAFT

Export your skin pack.

One ZIP with your skins, animations, and rules.

0animations
0frames
0rules

You can import this ZIP later to keep editing.

Add it to Minecraft

  1. Install Expressionful 1.2.0 and Fabric API for Minecraft 26.2.
  2. Put the exported ZIP in your instance's skinpacks folder.
  3. Press K, click Refresh, and select your pack.

For other players to see it, the server and those players also need the mod. Enable Share in the mod's pack picker.

    CONDITION REFERENCE
    Aliases & attributes
    Use these in rules or assign them to animations in the JSON aliases section.
    { "aliases": {
  "wasdamaged": "hurt",
  "hunger == 2": "hungry",
  "health == 1": "critical",
  "has_speed": "speedy"
} }
    Health uses HP: 1 HP = half a heart. hearts == 1 means 2 HP. Hunger uses points: 2 points = one food icon. Use hunger_bars == 2 for two icons.
