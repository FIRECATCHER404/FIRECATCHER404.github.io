Expression settings

Choose an expression to edit its playback and preview.

Continuous playback stops when you reopen a skin menu, select another expression, or an automatic rule takes over. It uses the animation's loop-start frame.

Body-part choices change the thumbnail; the expression changes your full skin. Requires Expressionful 1.6 or newer.

READY FOR MINECRAFT

Export your skin pack.

One ZIP with your skins, animations, and rules.

0animations
0frames
0rules

You can import this ZIP later to keep editing.

Add it to Minecraft

  1. Install Expressionful and Fabric API for your Minecraft version.
  2. Put the exported ZIP in your instance's skinpacks folder.
  3. Press K, select your pack, then click Apply and close. You can also drag the ZIP into that menu.

For other players to see it, the server and those players also need the mod. Enable Share my skin in the mod's Settings screen.

Advanced: pack JSON files

The ZIP includes skinpack.mcmeta for presentation, skinpack.json for animations, and your optional pack.png icon.

    CONDITION REFERENCE
    Aliases & attributes
    Use these in rules or assign them to animations in the JSON aliases section.
    { "aliases": {
  "wasdamaged": "hurt",
  "hunger == 2": "hungry",
  "health == 1": "critical",
  "has_speed": "speedy"
} }
    Health uses HP: 1 HP = half a heart. hearts == 1 means 2 HP. Hunger uses points: 2 points = one food icon. Use hunger_bars == 2 for two icons.
