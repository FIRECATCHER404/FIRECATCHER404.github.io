Minecraft note block source sounds - Java Edition 26.3

20 instrument samples, 19 mob-head clips, 2 alternate samples.
Includes every block.note_block.* sound event and every audio file in sounds/note/.

OGG files are unchanged copies of the installed game assets; SHA-1 hashes were verified.
WAV files are decoded PCM16 audio, produced with:
vgmstream CLI decoder r2168-26-g68021534 (Nov  5 2026)
Command: vgmstream-cli -i -o output.wav input.ogg

These are base recordings, not separately rendered note pitches. The game changes
playback speed for different notes. The creeper-head event uses its source at half speed.
The browser preview applies that event pitch; downloads preserve the source recording.
catalog.json records source paths, events, event pitches, formats, and checksums.
